# 🎓 南信实验报告工坊 (NUIST Lab Report Studio)

一个**本地运行**的实验报告自动生成网站，专为南京信息工程大学的课程设计：
**C语言程序设计**（语法基础 / 程序控制结构 / 函数 / 数组 / 指针 / 结构体）、
**工程制图**（AutoCAD 上机）等。

你上传老师发的**模板 docx**（如「学号 姓名 实验报告-4 数组及其应用.docx」、
「实验2.docx」），它自动解析模板结构、理解实验要求，直接补全成一份完整的实验报告：
填写页眉信息、逐题生成代码并渲染成代码截图、（有编译器时）真实编译运行并把控制台结果截图插入
"实验步骤和实验结果"、自动撰写"分析与讨论"；工程制图则生成完整绘图步骤并预留截图位。

右侧有**交互窗口**：不满意随时用一句话修改（"把姓名改成张三"、"第2题换一种思路"、
"重写分析与讨论"），左侧有**实时预览框**，改完立刻看到效果，最后一键下载 docx / 导出 PDF。

---

## 快速开始

1. 安装 Python 3.9+（安装时勾选 *Add to PATH*）
2. 双击 **`start.bat`** —— 首次运行会自动安装依赖（python-docx、Pillow），然后自动打开浏览器
3. 按界面上的 ①②③④ 步骤操作即可

> 数据全部保存在本机 `data/` 目录，服务只监听 127.0.0.1，不经外网。

## 功能总览

| 功能 | 说明 |
|---|---|
| 模板解析 | 识别页眉/正文表单里的 姓名、学号、学院、专业、年级、班次、指导教师、日期、实验名称 等字段；识别 1．实验目的 / 2．实验内容 / 3．实验步骤和实验结果 / 4．分析与讨论（或 一、二、三、四）章节与（1）（2）任务 |
| 内容生成 | C语言：从模板任务生成可编译的 C 代码 → 渲染成代码截图（VS Code 风格）→ 找到 gcc 时自动编译运行、截取控制台输出插入报告；问答题自动写答案；分析与讨论逐实验撰写。工程制图：生成图层/中心线/圆/阵列/修剪/偏移/标注等完整步骤 |
| 插入图片 | 上传截图后点"插入报告"，或聊天说"插入图片 xxx.png"；支持插入到指定段落之后 |
| 软件权限 | 聊天里点「🛠 申请软件权限」描述需求（如"打开 AutoCAD 画图并截图"），系统给出**待批准命令卡片**，你逐条批准后才执行；执行可自动截屏作为过程截图 |
| 预览框 | 中间 A4 纸样式实时预览（含页眉信息），点击预览中的段落可在聊天里精确修改 |
| 交互窗口 | 一句话修改：改字段 / 改段落 / 删除段落 / 重新生成第N题 / 重新运行第N题 / 重写分析 / 补充内容 |
| 导出 | 下载 docx（文件名自动为「学号 姓名 实验报告.docx」）；导出 PDF（需本机装有 LibreOffice 或 Microsoft Word） |
| AI 增强（可选） | ⚙ AI 设置里配置任意 OpenAI 兼容接口（DeepSeek / 通义 / Kimi / GLM…）后：代码按你的任务描述定制生成、分析与讨论更个性化、聊天理解任意自然语言修改。**不配置也能用**——内置南信大课程知识库 |

## 想让程序真正跑起来（推荐）

自动运行并截图需要 C 编译器，任选其一安装后重启本工具即可自动检测：

- **MinGW-w64**：https://winlibs.com 下载后把 `bin` 加入 PATH
- **Dev-C++**（自带 MinGW，很多同学已装）：安装后工具会自动在常见目录找到 gcc
- 也可以不装：报告里插入代码截图，运行结果你自己截图后从左侧上传插入

## 目录结构

```
nuist-lab-report/
├─ start.bat            双击启动
├─ server.py            本地网站服务端（标准库实现，仅 python-docx/Pillow 依赖）
├─ engine/              核心：docmodel(docx解析编辑) courses(南信大课程知识库)
│                       filler(生成引擎) render(代码/控制台截图渲染) runner(权限执行)
│                       llm(可选AI) intent(聊天意图) preview(网页预览) convert(PDF导出)
├─ web/                 前端（预览框 + 交互窗口 + 权限审批卡片）
├─ samples/             两份与南信大真实模板同构的示例模板（make_samples.py 生成）
├─ tools/               inspect_docx.py 结构解析 / e2e_test.py 端到端测试 / make_demo.py
└─ data/                会话数据（上传的模板、生成的报告、截图素材）
```

## 测试

```

python tools/e2e_drawing.py     # 工程制图全流程
```

已用真实的南信大空模板（数组及其应用）验证：字段填充、章节定位、代码截图、
聊天修改、权限执行、docx 输出全部通过。

## 隐私与安全

- 服务只监听本机回环地址，不上传任何数据
- 所有命令执行都需你在网页上**逐条批准**，命令原文可见，可拒绝
- AI 增强开启时，模板内容/任务描述才会发送给你自己配置的 API 服务商
